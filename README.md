# Wedding Cuts

스튜디오와 야외 웨딩 촬영을 위한 20페이지 컷 구성 one-pager입니다.

## Files

- `wedding_album_onepager.html`: 컷별 이미지 갤러리 HTML
- `cut_images_manifest.json`: 컷별 이미지 목록
- `컷별_이미지/`: 컷 주제별 이미지 폴더

## Public URL

GitHub Pages를 `main` 브랜치 root로 활성화하면 아래 주소에서 볼 수 있습니다.
